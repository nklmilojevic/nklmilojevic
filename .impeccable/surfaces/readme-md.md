## Direction contract

THESIS: Each project is a street in Belgrade; its latest release is the house number on the wall. Refuses the category default of emoji bullet lists, stats cards and skill-badge walls.

OWN-WORLD: Blue vitreous-enamel plates (#1b4592 field, #f5f7fa ink, one white inset border as the only ornament), Cyrillic name over Latin name in a condensed grotesk (Fira Sans Condensed, embedded); the name plate carries a district strip under a rule, street and house plates carry only name and number/date.
